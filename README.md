# 🎬 Movie App

A movie browsing web application built with React, TypeScript, and the TMDB API.

The app allows users to browse popular and top-rated movies, search through movie data, view movie details, and navigate between different pages.

## 🚀 Features

- Browse popular movies
- Browse top-rated movies
- Dynamic movie hero section
- Automatically changing featured movie
- Movie search
- Movie detail pages
- Movie ratings and release dates
- Movie descriptions and poster/backdrop images
- React Router navigation
- Responsive layout
- Animated background using Grainient
- Data fetched from the TMDB API

## 🛠️ Technologies

- **React**
- **TypeScript**
- **React Router**
- **Tailwind CSS**
- **Vite**
- **TMDB API**
- **Grainient / React Bits**
